# Robonine SO-ARM101 Black & White

3D printing projects and packaging drawings for Robonine’s black-and-white version of the SO-ARM101 robot arm.

## 3D printing

Open the `.3mf` projects in Bambu Studio. Check the printer and filament settings before slicing.

| Project | File |
| --- | --- |
| Leader arm | [SO-ARM101_Leader_Robo9.3mf](printing_parts/3mf/SO-ARM101_Leader_Robo9.3mf) |
| Follower arm | [SO-ARM101_Follower_Robo9.3mf](printing_parts/3mf/SO-ARM101_Follower_Robo9.3mf) |
| Robonine logo with a black base | [logo_black_base.3mf](printing_parts/3mf/logo_black_base.3mf) |
| Robonine logo with a white base | [logo_white_base.3mf](printing_parts/3mf/logo_white_base.3mf) |
| Colored figures | [colored_figures.3mf](printing_parts/3mf/colored_figures.3mf) |
| ArUco cube | [aruco_cube.3mf](printing_parts/3mf/aruco_cube.3mf) |
